# STEP 05: ログイン画面と画面の土台

| | |
|---|---|
| 状態 | 完了 |

## 目的

ログイン画面と、ログインしていないと入れない画面の仕組みを作る。
あわせて、以降の画面すべてが乗る土台（ルーティング・サーバ状態の管理・API 呼び出しの共通処理・スタイリング・画面のテスト）を決める。

この STEP から、**仕様・設計・技術選定の判断がユーザーから委任された**。
基準は「実務の主流か」「このプロジェクトに合うか」「標準的なセキュリティ水準を満たすか」。CLAUDE.md もこの進め方に書き換えた。

## なぜそうしたか

| 判断 | 採用案 | 対案と外した理由 |
|---|---|---|
| ルーティング | TanStack Router（ファイルベース） | **React Router（最大の主流）**。型の恩恵が強いのはサーバ側も持つ使い方で、SPA の今回は薄い。TanStack Router は十分に主流で、パスとクエリを型で検査でき、「端から端まで型で繋ぐ」という本プロジェクトの主題に合う |
| ルートの定義方法 | ファイルベース（TanStack 推奨） | コードで木を組む方式。仕組みは見えやすいが、記述量が多く TanStack 自身も推奨していない |
| スタイリング | Tailwind CSS v4 | CSS Modules（依存なし）は CSS 自体を学ぶなら良いが、学ぶ対象は React / TS。shadcn/ui は実務で多いが、部品の中身を自分で書かなくなるので今は入れない |
| API 呼び出しの共通処理 | `hono/client` の `parseResponse` | 自前の `ApiError`。作る直前に、同じことをする関数が Hono に既にあると分かった |
| ログイン状態の持ち方 | `/api/auth/me` の結果だけ（TanStack Query） | localStorage 等にも持つ。Cookie の実際の状態とずれる |
| 認証ガードの位置 | ルートの `beforeLoad`（描画前） | コンポーネントの中で判定。未ログインでも中身が一瞬描画される |
| セッション切れ | QueryCache / MutationCache の `onError` で一括処理 | 画面ごとに 401 を処理する。漏れが出る |
| ログアウト後 | キャッシュを丸ごと消す（成功時のみ） | 消さない。次にログインした人に前の人のデータが見える |
| 戻り先の検証 | URL として解釈し、オリジンが変わらないか確認 | 先頭が `/` かどうかだけ見る。`/\evil.example` を通してしまう（下記） |
| 画面のテスト | アプリ全体を描画 + MSW（型付き） | 部品単体のテスト。「未ログインならログイン画面へ」のような画面をまたぐ振る舞いが確かめられない |
| E2E | 次の STEP 05b で Playwright | 今回入れる。範囲が膨らむ。ただ判断を任された以上、ブラウザでの確認も自動化すべきなので直後に回す |

## つまづき

| 事象 | 原因 | 解決 |
|---|---|---|
| `app.tsx` を書いたつもりが、既存の `App.tsx` の中身を上書きしていた | **macOS のファイルシステムは大文字小文字を区別しない**。ファイル名は `App.tsx` のまま残った | `forceConsistentCasingInFileNames` が TS1149 で検知。`git mv App.tsx app.tsx` で改名を git に伝えた |
| コミットの振り分けが崩れた | `git add` が「既にステージ済みの削除」のパスで失敗したのに、`&&` で繋いでいなかったため後続の `git commit` が走った。事前に `git mv` / `git rm` でステージ済みだった改名・削除が1件目に紛れ込んだ | push 前だったので `git reset --soft HEAD~2` で取り消し、パス指定コミットと `set -e` で振り分け直した |
| ルートの `pnpm test` の結果が空だった | Postgres のコンテナが止まっていた（`Exited (255)`、日が空いた間に Docker が再起動）。api のテストが `ECONNREFUSED` で落ち、出力の絞り込みで結果行が消えていた | `docker compose up -d`。**出力が空のときは絞り込まずに全文を見る** |
| 生成されたルート一覧が lint で `any` を指摘された | TanStack Router の生成物が内部で `any` を使う | Biome の対象から外した |

### 書く前に確かめて避けられたこと

- **MSW v3 で `onUnhandledRequest` が `onUnhandledFrame` に改名されていた**。
  リリースノートを読まずに v2 の書き方をしていたら、未定義のリクエストを見逃す設定になっていた
- **`hono/client` に `parseResponse` があった**。「2xx ならパース済みの本文、それ以外は `statusCode` 付きの例外」で、作ろうとしていたものそのもの。2xx の本文だけを型として返す

### 途中のコミットごとの型チェックは実施できていない

振り分け直したあと、一時的な worktree で各コミットの型チェックを試みたが、
オフラインでの依存インストールが失敗して検査自体が走らなかった。確認できているのは最終状態のみ。

## 気づき・学び

**一発で通ったテストほど疑う。**
web のテスト 24 件は最初の実行で全部通った。そこで守りたい性質を3つ同時に外したところ、
**それぞれに対応するテストだけが落ちた**（他は通った）。テストが狙ったものを見張っていると確認できた。

| 外したもの | 落ちたテスト |
|---|---|
| 戻り先の検証 | オープンリダイレクトの2件 |
| ログアウト時のキャッシュ削除 | ログアウトの1件 |
| セッション切れの一括処理 | セッション切れの1件 |

**「型で防いでいる」は成果物で確かめる。**
本番ビルドを検索し、サーバ側のコード（`drizzle-orm` / `argon2` / `DATABASE_URL` など）と
開発用ツールが1件も含まれていないことを確かめた。
STEP 01 から書いてきた「`import type` と `verbatimModuleSyntax` で API のコードが混入しない」が、初めて実物で確認できた。

**オープンリダイレクトは文字列の先頭を見るだけでは防げない。**
`/\evil.example` は `/` で始まるが、ブラウザは `\` を `/` とみなすので `//evil.example`（別サイト）になる。
ブラウザと同じ規則（WHATWG URL）で解釈して、オリジンが変わらないことを確かめるのが確実。

**新しいメジャー版は記憶で書かない。**
MSW v3 も React Router v8 も、私の知識の外にあった。リリースノートと、入ったパッケージの中身で確かめてから書く。

**ライブラリに既にあるものを先に探す。**
共通処理を作る前に、使っているライブラリの export を眺める。今回は `parseResponse` がそれだった。

**大文字小文字だけの改名は `git mv` で行う。**
macOS（区別しない）と CI の Linux（区別する）で挙動が違う。手元で動いても CI で「ファイルが無い」になる。

**前のコマンドの失敗を、後ろのコマンドに無視させない。**
複数の git 操作を1回で流すときは `set -e` か `&&` で繋ぐ。失敗を見逃した結果、意図しない内容のコミットができた。

**画面側の権限チェックは UX であって、守りではない。**
`/admin` の画面チェックは「見せない」ため。API を直接叩かれれば意味がない。守りの本体は API の `requireRole('admin')`。

## 次への申し送り

- **STEP 05b で Playwright を入れる。** 実際のブラウザ・API・DB を通しで確かめる。CI でもブラウザを入れて実行する
- **テストの前に `docker compose up -d` が必要。** 日が空くとコンテナが止まっていることがある
- 新しい画面は `apps/web/src/routes/_authenticated/` の下に置けば、自動でログイン必須になる。
  管理者用は `_authenticated/admin/` の下に置けば admin 限定になる
- API のモックは `src/test/handlers.ts` に、API の型を借りて足す
- 401 は自動でログイン画面へ送られる。ログインのように 401 を「正常な失敗」として扱う
  ミューテーションには `meta: { skipSessionExpiry: true }` を付ける
- `.claude/settings.json` に、作業中に許可された `Bash(pnpm -F @attendance/web test)` が追加されている。
  ユーザーの変更なのでコミットしていない
